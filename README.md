A tiny stack virtual machine for make.fun's tiny stack ISA (version 1).
Run with `node main.ts`: it reads `/input/<id>/program.bin` and
`/input/<id>/input.bin` for every instance and writes
`/output/<id>/stdout.bin` and `/output/<id>/exit.txt`.
